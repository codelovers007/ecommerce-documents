# Business Requirements – E-commerce Application

## Project Overview

The client wants to build an e-commerce platform where customers can browse, purchase, and review products online. The platform should provide a smooth shopping experience for customers while allowing administrators to manage products, inventory, and orders.

---

## Customer Requirements

1. Customers should be able to create an account.
2. Customers should be able to log in and log out securely.
3. Customers should be able to reset their password if they forget it.
4. Customers should be able to browse products by category.
5. Customers should be able to search for products by name.
6. Customers should be able to filter products by category, price, and brand.
7. Customers should be able to sort products by price, popularity, and newest arrivals.
8. Customers should be able to view detailed information about a product.
9. Customers should be able to add products to their shopping cart.
10. Customers should be able to update the quantity of items in their cart.
11. Customers should be able to remove products from their cart.
12. Customers should be able to save products to a wishlist.
13. Customers should be able to save multiple delivery addresses.
14. Customers should be able to select a delivery address during checkout.
15. Customers should be able to choose a payment method.
16. Customers should be able to place an order.
17. Customers should receive an order confirmation after placing an order.
18. Customers should be able to view their order history.
19. Customers should be able to track the status of their orders.
20. Customers should be able to cancel an order before it is shipped.
21. Customers should be able to rate and review purchased products.

---

## Admin Requirements

1. Admin should be able to log in securely.
2. Admin should be able to create, update, and delete products.
3. Admin should be able to manage product categories.
4. Admin should be able to manage product inventory.
5. Admin should be able to upload product images.
6. Admin should be able to view all customer orders.
7. Admin should be able to update order statuses (Pending, Processing, Shipped, Delivered, Cancelled).
8. Admin should be able to view customer information.
9. Admin should be able to manage customer reviews.
10. Admin should be able to view sales reports.

---

## Business Rules

1. A customer must be logged in before placing an order.
2. A product cannot be purchased if it is out of stock.
3. An order must contain at least one product.
4. Every order must have one delivery address.
5. Every successful payment should generate an order.
6. Customers can review only products they have purchased.
7. Order cancellation is allowed only before shipment.
8. Inventory should decrease automatically after a successful order.
9. Taxes and shipping charges should be calculated during checkout.
